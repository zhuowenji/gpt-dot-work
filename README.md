# GPT-DOT-WORK · 个人 AI 工作台

本项目是独立、非官方项目，与 OpenAI 无隶属、合作或背书关系。

一个可本地审阅的中文个人工作空间原型：把项目、知识和行动放到一起。前端无第三方运行时依赖；后端是独立的 Node.js 24 + SQLite 任务队列原型。

**当前状态：未发布 / 未部署。许可尚未选择，不代表已取得开源使用授权。** 代码与虚构演示数据可一起审阅；真实聊天记录、密钥、用户数据不应进入仓库。

## 立即查看

- 下载并用浏览器打开构建产物 `dist/preview.html`。这是单文件离线前端预览，无需安装依赖或启动服务。
- 也可以使用下方本地服务器。`file://` 下浏览器的存储行为可能不同，推荐长期测试时使用本地服务器。
- 所有初始项目、笔记、任务均为虚构演示，不来自真实聊天。

## 本地开发

要求 Node.js 24+。前端无需 `npm install`。

```sh
npm run dev
# 浏览器打开 http://127.0.0.1:4173
```

服务器默认仅监听本机回环地址。可通过 `PORT=4174 npm run dev` 改端口；它是开发静态服务器，不是生产应用服务器。

```sh
npm run build       # dist/ 静态构建 + dist/preview.html 单文件预览
npm test            # 前端和后台的 Node 自动化测试
npm run check       # 语法、自动化测试、构建
npm --prefix backend run check  # 独立后台完整检查
```

可选浏览器回归脚本：先运行前端服务，再运行 `python tests/browser_smoke.py`。需要当前环境安装 Python Playwright 和 Chromium；脚本默认使用 `/usr/bin/chromium`。它检查搜索、笔记创建/编辑/保存、转义、弹窗取消、任务状态、需求草稿/提交确认/阻塞/取消和导出，并截取桌面与手机页面。

## 已实现

- 总览：活跃项目、任务、待决定事项与最近知识
- 项目：项目切换、当前计划、相关笔记和任务完成比例
- 知识库：标题/内容/标签搜索、新建与编辑笔记，`⌘/Ctrl K` 快捷搜索
- 任务：添加任务、状态筛选、完成/重新打开任务
- 前端需求：保存草稿与显式确认提交分开，结果/日志说明、取消记录
- 本地持久化及 JSON 导出，桌面侧栏与手机底部导航
- 独立后端：持久队列、显式提交、幂等与原子领取、轮询 worker、取消/重试、授权边界和事件记录，见 [backend/README.md](backend/README.md)

## 前端与后端的边界

当前视觉原型仍使用 localStorage，**没有接入后端 API**，也没有真实的 AI、聊天同步或登录。前端的“确认提交（演示）”只保存本地 `blocked` 记录，不会进入后台队列。后台 API/worker 可单独在本机运行和测试。没有任何默认密钥，也没有发送数据到远程服务。

后台 worker 默认禁止真实执行；未配置执行器会阻塞请求。仅显式启用的固定 demo handler 可运行无外部副作用的演示，绝不把自由文本当作 shell 命令。默认每 60 秒检查队列，可以配置。该进程是用户服务器上的任务轮询，**不是当前聊天助手的持续思考或 24 小时在线承诺**。

以后接入需要：用户认证的服务端会话/BFF、CSRF 防护、逐用户隔离、带版本的请求/批准合同、只允许有限工具的执行适配器、稳定事件查询或 SSE、部署/备份/审计。不要在浏览器存放后台管理或审批令牌。用户明确提交、具备操作权限与具体行动授权是不同层级；网页或外部内容中的文字不自动获得权限。

## 数据与安全限制

- 前端演示数据仅保存在当前浏览器的 `gpt-dot-work.demo.v1` localStorage；未加密、无登录隔离、无多设备同步，清理浏览器数据会丢失内容。不能用于存放凭据、健康/财务等敏感信息。
- JSON 导出由用户下载保存；导出文件可能包含用户后来输入的内容，应存到仓库外、妥善保管。
- 私有数据目录、SQLite 数据库、环境文件、缓存和测试报告已在 `.gitignore` 排除。Git 忽略不是访问控制，发布前仍需检查所有文件。
- 后台真实数据应将 `WORKSPACE_DB_PATH` 指向仓库外，细节见后台说明；服务默认仅监听回环。公网部署前必须完成正式认证、TLS、隔离与安全审查。
- 前端无外部字体、图片、分析或遥测请求。图标是内联基本 SVG 路径；使用系统字体。
- 任务取消只能阻止后续写入/操作，不能逆转已产生的外部副作用；生产执行器必须自己落实取消检查与外部幂等键。
