## 2. “毫秒级后端接收”的测量定义

用户要求：毫秒级后端接收。本轮采用 **十并发时服务端接收 p95 ≤ 200 ms** 的工程目标；200 ms 不是用户指定数字，也不是已承诺的生产 SLO。

分别记录：

1. **后端接收**：Node 发出 HTTP request 事件至应用准备发送回执，期间完成 SQLite 事务提交。
2. **客户端 ACK**：客户端发起请求至完整解析响应；包含客户端、HTTP 和传输开销。
3. **AI 启动**：入库至真实平台开始处理或取得任务，须以实际可观测点说明。
4. **AI 回复**：开始处理至回复/上下文提交；另记录入库至前台显示的总时间。

872a551 在成功创建/追加的 201 响应提供 `Server-Timing: intake-receipt`，范围为 HTTP 处理函数入口至提交后的回执准备。本地旧基线使用独立夹具计时；比较不同环境前须核对边界，不能将两次测试混为同一组样本。

后端接收不包含 DNS、TLS、互联网传输、request 回调前的排队或页面渲染。客户端时间减服务端时间也不能被称为“纯网络耗时”。若生产未提供对应计时，只能记录客户端 ACK，后端 p95 必须标为未测，不能替代。

- 接收：实际后端 p50/p95/p99、客户端 ACK、错误率、测量范围。
